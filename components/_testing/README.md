# \_testing

This folder contains utilities, helpers, and example components for testing UI and features in the MediMatc project.

## Structure

- **error-testing/**: Components and helpers for simulating and handling error states in the UI.
- **ui-testing/**: Example components and utilities for visual and interaction testing of UI elements.

## Purpose

- Provide a safe space for developing, previewing, and verifying new UI components and patterns.

## Usage

- Use components in this folder for local development, debugging, and visual regression testing.
- Do not import from `_testing` in production code.
- Feel free to add new subfolders for specific testing scenarios or tools.

---

For more details, see the individual `README.md` files in each subfolder.
