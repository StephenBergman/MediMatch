# React Native Paper Kitchen Sink

This directory contains a lightweight kitchen sink used to preview a handful of React Native Paper components.

## Purpose

- Showcase and test Paper components in a live environment.
- Serve as a quick reference for usage patterns and cross-platform behavior.
- If a component doesn't behave as expected, capture notes directly in this screen.

## Usage Standards

- All components should use React Native Paper primitives as the primary building blocks.
- Ensure all examples are compatible with Expo (native and web).
- Prefer cross-platform code; use platform-specific files only when necessary.
- Use clear, concise code snippets and add comments for non-obvious logic.
- Document any custom logic or workarounds for platform differences.

## `<ComponentSnippet>`

- Used to display examples and notes about Paper elements.
- Displays snippets, usage examples, and any warnings/errors we discover.

## Known Component Issues

We removed the large grid of Gluestack demos; only the simplified Paper examples remain. Add issues or notes directly in code if needed.
